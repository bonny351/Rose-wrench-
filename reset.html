Rose Wrench Firebase Reset

Resets the scheduler data so the appointment page can start from a clean Firebase setup.

What this page resets

  • scheduler/settings
  • All documents in scheduler/settings/services
  • All documents in scheduler/settings/bookings
  • Then creates the default shop hours and services used by the scheduler.

⚠️ Permanent action

This deletes the scheduler's existing services and appointments from Firestore. It does not delete your products_bracelets collection.
